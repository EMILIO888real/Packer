# Security Policy

## Supported Versions

Only the latest stable release of the software is actively supported. Security patches will be provided for the latest stable release. Older versions won't receive security updates.

## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability, please do NOT open a public GitHub issue.

### Preferred Method
Submit a report privately via GitHub's **Private Vulnerability Reporting**:
1. Navigate to the **Security** tab of this repository.
2. Select **Advisories** and click **Report a vulnerability**.

### Alternative Method
If you cannot use GitHub's private reporting, email us at **emilspro888@gmail.com**.

## What to Expect
* **Initial Response:** Within 48 hours acknowledging receipt.
* **Triage:** Within 5 business days with a preliminary assessment or request for more details.
* **Public Disclosure:** Coordinated release once a patch is tested and deployed.
